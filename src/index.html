⌘I Agent

Describe the task. Review the diff.

The agent explores your project with glob, grep and read, changes code with edit and write, and runs your tests with bash until they pass. Every file it touches is listed with a diff, Keep and Revert — and it asks before running commands.

⌘K Inline edit

Edit in place

Select code, say what to change, and watch it stream into a diff. Accept with ⌘↵.

Up and running in three steps

  1. 1

    Install Ollama

    Ollama runs the models. Grab it from ollama.com/download and open it.

  2. 2

    Pull a coding model

    One model covers chat, the agent and autocomplete.

    ollama pull qwen2.5-coder:7b
  3. 3

    Get Typist

    Download the app for your computer, or run it from source:

    Download Typist
    git clone https://github.com/soft-boy/typist.git cd typist && npm install typist .

    Needs Node.js 20.19+ and git. npm install adds the typist command to your PATH.
