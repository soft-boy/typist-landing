Up and running in three steps

  1. 1

    Install Ollama

    Ollama runs the models. Grab it from ollama.com/download and open it.

  2. 2

    Pull a coding model

    One model covers chat, the agent and autocomplete.

    ollama pull qwen2.5-coder:7b
  3. 3

    Get Typist

    Download Typist, open the .dmg, and drag Typist into your Applications folder.

    Download Typist

    Opening it the first time

    Typist isn’t notarized by Apple yet, so macOS asks you to confirm once:

    1. Open Typist from Applications. When macOS says it can’t verify the app, click Done.
    2. Open System Settings → Privacy & Security, scroll down, and click Open Anyway.
    3. Confirm with Open. After that it opens like any other app.

    Opening it the first time

    If Windows SmartScreen warns you, click More info, then Run anyway.

    Opening it the first time

    Make the AppImage executable with chmod +x Typist-*.AppImage, then run it.

    Typist also adds a typist command, so typist . opens any folder from your terminal.
